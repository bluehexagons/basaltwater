# Native Windows T3 environment

Native Windows and WSL providers have separate homes, settings and skills.
Choose the local Windows connection for native projects. T3 owns its worktrees;
use live exposed orchestration/browser tools and the active session's policy.
Installing T3 does not grant an independent provider those tools.

For account, connection or loaded-skill mismatches, use shared
[execution-environment checks](https://github.com/bluehexagons/basaltwater/blob/main/common/agent_skills/basaltwater-project-development/references/t3-workflows.md#establish-the-execution-environment).
For stable 0.1.6 side chats, project pin/archive, local commit review and optional
1Password sources, read
[client workflows](https://github.com/bluehexagons/basaltwater/blob/main/common/agent_skills/basaltwater-project-development/references/t3-workflows.md#shared-016-client-workflows).
The [0.1.7 workflows](https://github.com/bluehexagons/basaltwater/blob/main/common/agent_skills/basaltwater-project-development/references/t3-workflows.md#shared-017-client-workflows)
cover child approvals, thread links, usage filters and model history.

Before policy diagnostics read
[CLI installation and Windows/WSL policy boundaries](https://github.com/bluehexagons/basaltwater/blob/main/common/agent_skills/basaltwater-project-development/references/t3-platforms.md).
Enable the bundled command via Settings → About → t3 command → Install;
open a new terminal and verify the selected `t3`. Managed Windows policy disables
desktop WSL environments; an absent distro is not proof of failed setup.
Do not run Linux `t3 service protect` for the Windows desktop.

An authorized `basaltw refresh` delivers updated skills and available WinGet T3
updates. WinGet can lag upstream; verify About, a provider turn and a terminal
after completion. Read [setup lifecycle](setup.md) before refresh. Authenticate
selected providers as this account and preserve permissions/approval settings.
Use the installed `basaltwater-t3-preview-testing` skill only when browser work
applies; it does not install Playwright or configure a browser.
