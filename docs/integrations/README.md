# Optional project integrations

Basaltwater's general profiles and commands work independently of these
project-specific guides. Choose an integration only when working on that
project; its repository remains authoritative for dependencies, tests and releases.

| Integration | Scope |
| --- | --- |
| [Antistatic](antistatic/README.md) | Lobby/database services, native game development, Animator, assets and runner inputs |
| [snake2d example](snake2d.md) | Project-owned Godot commands on native Windows |

Examples describe supported interfaces with fictional deployment values. Keep
private project inventories, customer details and operational evidence outside
Git according to the [documentation privacy rules](../agents/project-standards.md#documentation-and-private-operational-state).
