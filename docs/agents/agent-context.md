# Agent context budgets

Managed defaults compact earlier in supported coding tools. Larger prompts can
increase usage and cross per-token pricing thresholds. Context overrides apply
at the scope the user chooses for the task or session.

Read the relevant instructions and sources for the task. Keep verbose output in
private artifacts and pass bounded findings to the parent before context fills.
Use the [project-development skill](../../common/agent_skills/basaltwater-project-development/SKILL.md)
for the ordinary edit and verification loop.
