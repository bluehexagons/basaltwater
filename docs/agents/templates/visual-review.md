# Visual review

- Requirement and expected observable result:
- Checkout, tested commit/dirty state, asset/scene/frame/camera:
- Requested settings and actual observed settings:
- Backend, renderer/device, application version, resolution/scaling, seed:
- Evidence paths (before/after, editable source/export, settings, report, logs):
- Observed results (complete image edges/content, dimensions, alpha, consuming-project behavior):
- Proposed changes / unresolved objections:
- Unverified checks (UI interaction, GPU, audio, timing, other platforms):
- Running or uncertain jobs, status/cleanup commands and checkpoint:

Keep raw captures/logs and exact operational details in private state outside
Git. Review selected evidence for personal infrastructure and user data before
including it in tracked summaries; use repository-relative paths and omit private
endpoints, account paths and job handles.

Follow [visual comparisons](../../workstations/visual-comparisons.md). Exit status
and difference counts alone do not establish visual correctness.
