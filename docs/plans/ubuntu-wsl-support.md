# Ubuntu WSL qualification status

Bootstrap, profiles, and native jobs are implemented. The [operator guide](../workstations/windows-wsl.md)
describes current behavior and manual checks.

Live Windows qualification remains open and is required before declaring
Windows/WSL support production-ready. WSL is outside the current v2.0.0 stable
release gate; add a dedicated case to the [release matrix](../release-qualification.md)
if that scope changes.
