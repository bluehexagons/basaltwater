# Web panel

The optional web panel shows health, services, storage, maintenance, and agent
tasks for one managed machine. T3 coding sessions use the native workspace.
Independent host tasks use the panel account's installed Codex CLI.

For route contracts and JSON shapes, see the [panel reference](web-panel-reference.md).
